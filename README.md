# Lab 2 — Web Application Security

## Описание проекта

В рамках лабораторной работы разработано небольшое веб-приложение MiniShop на Python с использованием Flask и SQLite.

Цель работы — изучить распространённые уязвимости веб-приложений, продемонстрировать их работу и показать способы устранения.

## Используемые технологии

- Python 3.12
- Flask
- SQLite
- HTML
- Git

## Реализованные уязвимости

### 1. SQL Injection (SQLi)

Уязвимость реализована в функции поиска товаров.

В уязвимой версии SQL-запрос формируется с использованием пользовательского ввода.

Исправление: использование параметризованных SQL-запросов.

### 2. Cross-Site Scripting (XSS)

Уязвимость реализована на странице приветствия пользователя.

В уязвимой версии отключено автоматическое экранирование пользовательского ввода.

Исправление: использование стандартного HTML-экранирования Jinja2.

## Структура проекта

- app.py — основное веб-приложение.
- database.py — создание и заполнение базы данных.
- exploit.py — скрипт проверки уязвимостей.
- templates/ — HTML-страницы.
- patches/ — файлы исправлений.
- screenshots/ — скриншоты результатов.

## Установка и запуск

1. Клонировать репозиторий.
2. Установить зависимости:

   pip install -r requirements.txt

3. Запустить приложение:

   python app.py

4. Открыть в браузере:

   http://127.0.0.1:5000

## Проверка уязвимостей

Для запуска тестового скрипта:

   python exploit.py

Проверки выполняются на локальном учебном приложении.

## Результаты

В уязвимом режиме тестовый скрипт обнаруживает SQL Injection и XSS.

В безопасном режиме SQL-запросы используют параметры, а пользовательский HTML экранируется.

## Исправления

Исправления представлены в формате diff в папке patches.

## Заключение

В ходе лабораторной работы разработано веб-приложение, реализованы две учебные уязвимости, проведена их проверка с помощью Python и рассмотрены способы устранения.
